# 像素童话大冒险

一款像素风格的横版平台跳跃游戏，灵感来源于经典的超级马里奥。

## 游戏特色

- 🎮 经典横版平台跳跃玩法
- 🏰 五大世界 × 3 关 + BOSS 战
- 🍄 丰富的道具系统（蘑菇、星星、火焰花、护盾）
- 👾 多样的敌人类型
- ⏪ 时间回溯功能
- 🎨 复古像素美术风格
- 🎵 全场景芯片音乐（主菜单 / 五大世界 / BOSS战 / 通关庆祝）

## 操作说明

| 按键 | 功能 |
|------|------|
| ← → / A D | 左右移动 |
| 空格 / ↑ / W / Z | 跳跃 |
| Shift / X | 奔跑加速 |
| R | 星辰回溯 |
| P | 暂停 |
| M | 音效开关 |
| F | 全屏 |

## 音乐系统

内置 8 种场景的芯片合成音乐，基于 WebAudio 实时生成，无需加载外部文件：

| 场景 | 音乐风格 |
|------|----------|
| 主菜单 | 轻快活泼 |
| 世界1 · 草原 | 明亮明快 |
| 世界2 · 森林 | 幽深静谧 |
| 世界3 · 沙漠 | 燥热奔放 |
| 世界4 · 冰川 | 清冷空灵 |
| 世界5 · 城堡 | 压迫紧张 |
| BOSS战 | 急促激烈 |
| 通关庆祝 | 胜利激昂 |

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- Web Audio API（实时合成音效与背景音乐）
- 像素风游戏美术

## 项目结构

```
├── index.html      # 游戏入口
├── js/
│   ├── core.js     # 核心引擎 + 音频系统
│   ├── game.js     # 游戏主逻辑
│   ├── entities.js # 实体（角色、敌人、道具）
│   ├── levels.js   # 关卡数据
│   └── rewind.js   # 时间回溯系统
└── README.md       # 项目说明
```

## 本地运行

直接用浏览器打开 `index.html` 即可游玩。
