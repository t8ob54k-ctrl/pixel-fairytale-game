# 像素童话大冒险

一款像素风格的横版平台跳跃游戏，灵感来源于经典的超级马里奥。

## 游戏特色

- 🎮 经典横版平台跳跃玩法
- 🏰 多个精心设计的关卡
- 🍄 丰富的道具系统（蘑菇、星星、火焰花）
- 👾 多样的敌人类型
- ⏪ 时间回溯功能
- 🎨 复古像素美术风格

## 操作说明

| 按键 | 功能 |
|------|------|
| ← → / A D | 左右移动 |
| 空格 / ↑ / W | 跳跃 |
| Shift | 奔跑加速 |
| R | 时间回溯 |

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- 像素风游戏美术

## 项目结构

```
├── index.html      # 游戏入口
├── js/
│   ├── core.js     # 核心引擎
│   ├── game.js     # 游戏主逻辑
│   ├── entities.js # 实体（角色、敌人、道具）
│   ├── levels.js   # 关卡数据
│   └── rewind.js   # 时间回溯系统
└── README.md       # 项目说明
```

## 本地运行

直接用浏览器打开 `index.html` 即可游玩。
